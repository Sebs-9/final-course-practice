# 5 分钟课堂演示材料提纲

## 1. 演示目标

在 5 分钟内说明项目背景、系统设计、核心功能、测试结果和软件工程制品完整性。

## 2. PPT 建议页

| 页码 | 标题 | 主要内容 |
|---|---|---|
| 1 | 项目概述 | 选题方向、项目名称、目标用户、核心价值 |
| 2 | 需求分析 | 利益相关方、核心用例、功能与非功能需求 |
| 3 | 软件设计 | 分层架构、模块划分、数据库与接口 |
| 4 | 系统演示 | 登录、监控看板、设备控制、告警联动、语音指令 |
| 5 | 测试与项目管理 | 测试结果、风险应对、版本管理、提交材料 |

## 3. 现场演示话术

1. 本项目选择全屋智能系统方向，聚焦家庭安防监控，并加入语音控制和场景联动。
2. 系统包含管理员、家庭成员、访客三类角色，支持多房间和多设备管理。
3. 架构上采用表现层、接口层、业务逻辑层和数据访问层，使用 SQLite 保存数据。
4. 演示核心流程：登录系统，查看监控，模拟入侵告警，系统生成录像并联动警报器，然后处理告警。
5. 语音输入框模拟语音识别结果，可以执行“打开客厅灯”“启动离家安防”“模拟厨房烟雾”等指令。
6. 自动化测试覆盖 29 条服务级和接口级路径，当前全部通过。
